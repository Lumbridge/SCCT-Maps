Shipment v1.7 - Splinter Cell: Chaos Theory Versus
Updated 6 October 2026

CHANGES
- Much more scenery: over 300 new props, including props from Call of
  Duty 4's Shipment and Bog, and Brutalist textures.
- Twice the lights (63, up from 31) and more effects, including falling
  debris (23 particle emitters, up from 8).
- The map is split into 22 zones, up from 6.
- 9 breakable glass panes.
- The map's own character skins and outfits for spies and mercs.
- A new map-selection picture and lobby plan.
- A smaller download: the map now carries the assets it uses, so it no
  longer needs ShipD_TXT.utx (40 MB) or any of the ported packages.
- Game modes, limits and lives are as in v1.6.

INSTALL
Close the game and extract this ZIP. Copy the enclosed Packages folder into
your Versus installation directory, merging its folders. For standalone
Enhanced SCCT Versus, use the directory containing Packages and System.
Start Versus and select Shipment.

Back up older ShipD files before replacing them. Keep the filenames and
subfolders intact. All players should use the same map version and packages.
ShipD_TXT.utx from earlier versions is no longer used and can be removed.

Included playable files:
Packages/Maps/ShipD.sdc
Packages/StaticMeshes/ShipD_STM.usx
Packages/Textures/ShipD-i.utc

Everything else the map uses comes with Enhanced SCCT Versus 4.0.

The matching editor source is available in the repository at
release/ShipD/v1.7/Packages/MapsEd/ShipD.sdc, outside this playable ZIP.
