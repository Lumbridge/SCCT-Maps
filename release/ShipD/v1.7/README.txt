Shipment v1.7 - Splinter Cell: Chaos Theory Versus
Updated 12 October 2026

CHANGES
- Over 300 new props, including props from Call of Duty 4's Shipment
  and Bog, and Brutalist textures.
- 68 lights, up from 31.
- 23 particle emitters, up from 8, including falling debris.
- 22 zones, up from 6.
- 9 breakable glass panes.
- The map's own character skins and outfits for spies and mercs.
- A new map-selection picture and lobby plan.
- Smaller download: the map carries the assets it uses, so it no longer
  needs ShipD_TXT.utx (40 MB) or any of the ported packages.
- Game modes, limits and lives are as in v1.6.

INSTALL
Close the game, extract the ZIP and copy its Packages folder into your
Versus installation (the folder that contains Packages and System),
merging folders. Start Versus and select Shipment.
Back up older ShipD files first. All players need the same version.
ShipD_TXT.utx from earlier versions is no longer used and can be removed.

Included playable files:
Packages/Maps/ShipD.sdc
Packages/StaticMeshes/ShipD_STM.usx
Packages/Textures/ShipD-i.utc

Everything else the map uses comes with Enhanced SCCT Versus 4.0.

Editor source (in the repository, not in this ZIP):
release/ShipD/v1.7/Packages/MapsEd/ShipD.sdc
