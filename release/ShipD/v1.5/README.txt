Shipment v1.5 - Splinter Cell: Chaos Theory Versus
Updated 17 September 2026

CHANGES
- Added seven seconds for mercenaries to reach the flood override buttons.
- Flooding begins at 7 seconds; damage begins at 27 seconds instead of 20.
- Shifted the remaining flood sequence by seven seconds; buttons expire at 47 seconds.

INSTALL
Close the game, extract the ZIP and copy its Packages folder into your
Versus installation (the folder that contains Packages and System),
merging folders. Start Versus and select Shipment.
Back up older ShipD files first. All players need the same version.

Packages/Maps/ShipD.sdc
Packages/StaticMeshes/ShipD_STM.usx
