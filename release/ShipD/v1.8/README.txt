Shipment v1.8 - Splinter Cell: Chaos Theory Versus
Released 13 October 2026

CHANGES
- Fixed a broken portal near the furniture pile.
- Fixed a broken portal near the merc elevator.

INSTALL
Close the game, extract the ZIP and copy its Packages folder into your
Versus installation (the folder that contains Packages and System),
merging folders. Start Versus and select Shipment.
Back up older ShipD files first. All players need the same version.
ShipD_TXT.utx from earlier versions is no longer used and can be removed.

Included playable files:
Packages/Maps/ShipD.sdc
Packages/StaticMeshes/ShipD_STM.usx
Packages/Textures/ShipD-i.utc

Everything else the map uses comes with Enhanced SCCT Versus 4.0.

Editor source (in the repository, not in this ZIP):
release/ShipD/v1.8/Packages/MapsEd/ShipD.sdc
