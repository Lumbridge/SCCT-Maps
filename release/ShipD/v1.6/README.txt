Shipment v1.6 - Splinter Cell: Chaos Theory Versus
Updated 24 September 2026

CHANGES
- Made the hackable laptop building more distinguishable.
- Improved sound using Reloaded v4.0 "only affect current zone".
- Improved zone coverage.
- Added GEs to stop spies falling to their deaths in the vertical vents
  between overground and underground.
- Made shipping container tops thicker so spy feet no longer clip through.
- Angled the lockers in the big pit.

INSTALL
Close the game, extract the ZIP and copy its Packages folder into your
Versus installation (the folder that contains Packages and System),
merging folders. Start Versus and select Shipment.
Back up older ShipD files first. All players need the same version.

Included playable files:
Packages/Maps/ShipD.sdc
Packages/StaticMeshes/ShipD_STM.usx
Packages/Textures/ShipD_TXT.utx
Packages/Textures/ShipD-i.utc
