Moonlight Park v1.0 - Splinter Cell: Chaos Theory Versus
Released 12 October 2026

An off-season British seaside amusement park at night. Package name: MoonD.

THE MAP
- Seven objectives, four to win: five laptops, a bomb site in the laser tag
  arena (three plant spots) and a disk to carry from the park office to
  the dodgems or the plaza kiosk.
- Working rides: the Magic Mouse coaster with two cars you can ride, a
  carousel with carts to hide in, a Ferris wheel you can board, a ghost
  train, a haunted house and a helter skelter with two zip lines.
- A spy monorail from a protected spawn station into the park, and
  tunnels under the park with hatches and gratings mercs can see and
  shoot through.
- Nine alarm cameras. Hacking the security terminal switches them all off
  for the round. Hacking the wheel's terminal sends the Ferris wheel out
  of control.
- The laser tag bomb blows holes in the building's walls.
- A main breaker switches the park's lights and rides, for both sides.

INSTALL
Close the game, extract the ZIP and copy its Packages folder into your
Versus installation (the folder that contains Packages and System),
merging folders. Start Versus and select Moonlight Park.
All players need the same version.

Included playable files:
Packages/Maps/MoonD.sdc
Packages/Textures/MoonD-i.utc

Everything else the map uses comes with Enhanced SCCT Versus 4.0.

Editor source (in the repository, not in this ZIP):
