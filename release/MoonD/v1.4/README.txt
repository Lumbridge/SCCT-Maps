Moonlight Park v1.4 - Splinter Cell: Chaos Theory Versus
Released 14 October 2026

An off-season British seaside amusement park at night. Package name: MoonD.

CHANGES
- The tin can alley and hook-a-duck roofs are solid; the invisible
  blocks above them are gone.
- Ledge grabs on the arcade's landing rails.
- The climbable fence by the spy station is gone. Spies leave over the
  compound wall by its ledges.

INSTALL
Close the game, extract the ZIP and copy its Packages folder into your
Versus installation (the folder that contains Packages and System),
merging folders. Start Versus and select Moonlight Park.
All players need the same version.

Included playable files:
Packages/Maps/MoonD.sdc
Packages/Textures/MoonD-i.utc

Everything else the map uses comes with Enhanced SCCT Versus 4.0.

The editable map is in the repository at
release/MoonD/v1.4/Packages/MapsEd/MoonD.sdc, outside this ZIP.
