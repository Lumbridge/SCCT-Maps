Moonlight Park v1.3 - Splinter Cell: Chaos Theory Versus
Released 14 October 2026

An off-season British seaside amusement park at night. Package name: MoonD.

CHANGES
- Mercs have a camera network: 16 cameras covering the plaza, the
  objectives, the drop-offs and the main routes. Open it with the
  camera network gadget. Hacking the security terminal blinds it too.
- The wall round the spies' exit by the station is higher and further
  out, with barred windows and locked doors you can see through. Spies
  climb it by the ledge on top.
- Spies board the monorail car by a ledge on its side.
- Smoother staircases.
- The carousel's horses and carts stop bullets.
- Rails on the coaster station's east stairs; the queue is solid.
- The GHOST HALT sign is readable.

INSTALL
Close the game, extract the ZIP and copy its Packages folder into your
Versus installation (the folder that contains Packages and System),
merging folders. Start Versus and select Moonlight Park.
All players need the same version.

Included playable files:
Packages/Maps/MoonD.sdc
Packages/Textures/MoonD-i.utc

Everything else the map uses comes with Enhanced SCCT Versus 4.0.

The editable map is in the repository at
release/MoonD/v1.3/Packages/MapsEd/MoonD.sdc, outside this ZIP.
