Moonlight Park v1.6 - Splinter Cell: Chaos Theory Versus
Released 16 October 2026

An off-season British seaside amusement park at night. Package name:
MoonD.

CHANGES
- The ghost train clown has a new laugh, and its horn is gone.
- The park music in the plaza is quieter.
- The ghost train exit is lit.

INSTALL
Close the game, extract the ZIP and copy its Packages folder into your
Versus installation (the folder that contains Packages and System),
merging folders. Start Versus and select Moonlight Park.
All players need the same version.

Included playable files:
Packages/Maps/MoonD.sdc
Packages/Textures/MoonD-i.utc

Everything else the map uses comes with Enhanced SCCT Versus 4.0.

The editable map is in the repository at
release/MoonD/v1.6/Packages/MapsEd/MoonD.sdc, outside this ZIP.
