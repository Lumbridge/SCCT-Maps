# Recovered / editable maps

Eden and Sublabs are existing community maps, separate from the original maps in this repository. These copies include the latest locally saved editable and compiled maps, plus custom assets and the original menu packages.

| Map | Map filename | Additional mesh package |
| --- | --- | --- |
| Eden | `EDE64.sdc` | `EDE64_Assets.usx` |
| Sublabs | `sub18.sdc` | `sub18_Assets.usx` |

Use Enhanced SCCT Versus 3.6 and the Reloaded Editor. Copy each complete `Packages` folder into the installation after backing up matching files. Open the map under `MapsEd` to edit it.

Recovered brush geometry does not retain the original construction history. Lighting can change after rebuilding. These files still need gameplay testing.

Both renamed editor maps passed ordinary load, rebuild, save, reopen, and T3D export checks on 13 September 2026.
