# Heliport 1.1 (HELI02)

Editable version of Heliport 1.1, recovered from the compiled map (recovered 17 September 2026). It replaces the installed `HELI02` map.

## Install

Close the game and the editor, back up files with the same names, then copy the `Packages` folder into your Enhanced SCCT Versus 3.6 installation.

- Playable map: `Packages/Maps/HELI02.sdc`
- Editable map: `Packages/MapsEd/HELI02.sdc` (open it in the Reloaded Editor)

It uses the standard Heliport meshes and textures from [the community pack](../../community/Heliport%201.1). Keep those installed.

## Known issues

- Brush history is not preserved (310 structural brushes rebuilt, 1,808 actors kept).
- The original baked lighting is kept. Rebuilding lighting will change the look.
- Not playtested in game.
