# Sublabs (sub18)

Editable version of Sublabs, recovered from the compiled map (saved 15 September 2026). It replaces the installed `sub18` map.

## Install

Close the game and the editor, back up files with the same names, then copy the `Packages` folder into your Enhanced SCCT Versus 3.6 installation.

- Playable map: `Packages/Maps/sub18.sdc`
- Editable map: `Packages/MapsEd/sub18.sdc` (open it in the Reloaded Editor)

Keep all the included mesh and texture packages, and do not rename `sub18_Recovered_Assets.usx`. The older `sub18_Assets.usx` is included for files that still use it.

## Known issues

- Brush history is not preserved (333 structural brushes rebuilt, 1,812 actors kept).
- The original baked lighting is kept. Rebuilding lighting will change the look.
- Not playtested in game.
