# Clarity Soft (ClarD)

Editable version of Clarity Soft, recovered from the compiled map (saved 15 September 2026). It replaces the installed `ClarD` map.

## Install

Close the game and the editor, back up files with the same names, then copy the `Packages` folder into your Enhanced SCCT Versus 3.6 installation.

- Playable map: `Packages/Maps/ClarD.sdc`
- Editable map: `Packages/MapsEd/ClarD.sdc` (open it in the Reloaded Editor)

Keep all the included mesh and texture packages, and do not rename `ClarD_Recovered_Assets.usx`. The older `ClarD_Assets.usx` is included for files that still use it.

## Known issues

- Brush history is not preserved (1,254 structural brushes rebuilt, 5,167 actors kept).
- The original baked lighting is kept. Rebuilding lighting will change the look.
- Not playtested in game.
