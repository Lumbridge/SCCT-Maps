# Clarity Soft (ClarD)

Recovered editable map and compiled map for Enhanced SCCT Versus 3.6.

Close the game and editor, back up existing files, then copy the included `Packages` folder into your game installation. These files replace the installed `ClarD` map.

Open `Packages/MapsEd/ClarD.sdc` in the Reloaded Editor. The playable map is in `Packages/Maps/ClarD.sdc`.

Keep `ClarD_Recovered_4_Assets.usx`, `claritysoft.utx`, and `ClarD-i.utc` with the map. Do not rename the asset package; the maps reference it by name.
