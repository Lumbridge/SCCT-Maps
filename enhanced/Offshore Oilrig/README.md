# "Enhanced" Offshore Oilrig

Enhanced version of Offshore Oilrig, saved as `OffsE`. Includes the playable map, the editable map, the map-selection package, the recovered mesh package and the other Oilrig packages these files use. Original map authorship and credits are kept.

## Changes (15 September 2026)

- Improved lighting.
- Fixed several incorrect textures.
- Spies can now pole-climb sections of the elevator when it is down.
- Fixed the broken flame emitter.
- Fixed several broken portal volumes.

## Install

Close the game and editor, back up files with the same names, then copy this folder's `Packages` folder into your **Enhanced SCCT Versus 3.6** installation. Keep all the included files together. Other players need the same files. `OffsE` does not replace the recovered `OffsD` version.

- Playable map: `Packages/Maps/OffsE.sdc`
- Editable map: `Packages/MapsEd/OffsE.sdc`

## Required installed packages

These come with the game and are not included here:

`Amb_Aqua`, `amb_Bank`, `Amb_Club`, `Amb_factory`, `Amb_Gare`, `Armes_impacts`, `Aquarium_STM`, `BNK_STM`, `FAC_STM`, `GAR_STM`, `Missile`, `STM_ORP`, `stm_war`, `TestMapStaticM`, `Aquarium_TXT`, `CTF_txt_xbox`, `Echelon`, `FAC_TXT`, `GAR_TXT`, `sfx`, `SGameplayObjectsTex`, `SGameplayObjectsTex_XBOX`, `TestMapTextures`, `TXT_BNK`, `TXT_ORP`, `txt_war`.

`dependencies.json` lists every asset the maps use, with its SHA-256. `SHA256SUMS.txt` covers the bundled files. Not playtested in game. Assets loaded only by scripts may need more files.
