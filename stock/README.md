# Stock maps

The maps that ship with the SVM 4.0 Public Beta install and are not elsewhere in this repository. They are unmodified copies of the installed files, kept here as a reference and as a starting point for edits.

These are Ubisoft's original game files. Your game already has them, so you do not need to install them.

| Folder | Contents |
| --- | --- |
| `Packages/Maps` | Playable maps (81) |
| `Packages/MapsEd` | Editable maps for the [Reloaded Editor](https://github.com/Lumbridge/SCCT_Versus_Reloaded_Editor) (75) |

`CineU`, `MounU`, `PrisD`, `PyroD`, `ShadD` and `VertU` have no editor version in the install.

Maps already in this repository (ShipD, MoonD, OffsD, OffsE, ClarD) are not repeated here.

Checksums for every file are in `SHA256SUMS.txt`.

The meshes, textures, animations and sounds these maps load are in the stock asset packs (`assets/svm-*`), one per map plus [Core game assets](../assets/svm-core/v1.0.0/README.md) and [Shared props](../assets/svm-shared-props/v1.0.0/README.md). Install them from the Map Manager's **Asset Packs** section.
