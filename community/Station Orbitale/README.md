# Station Orbitale

Community map `stationorb.sdc`, unchanged from the original pack, credits included. Not editable.

Close the game, back up files with the same names, then copy this folder's `Packages` folder into your SCCT Versus installation. Copy the shared [`_shared`](../_shared) files too. Keep the file names.

## Required installed packages

These come with Enhanced SCCT Versus 3.6 and are not included here:

`Amb_Aqua`, `Amb_Club`, `Amb_Tsp`, `Aquarium_STM`, `Aquarium_TXT`, `BNK_STM`, `CLU04_STM`, `Echelon`, `Mall_tibu_stc`, `SGameplayObjectsTex`, `STM_MALL`, `STM_ORP`, `TSP01_STM`, `TXT_BNK`, `TXT_ORP`, `TestMapStaticM`, `stm_war`, `txt_war`.

Not tested in game.
