# Museum Aftermath

Community map `DDMUS.sdc`, unchanged from the original pack, credits included. Not editable.

Close the game, back up files with the same names, then copy this folder's `Packages` and `System` folders into your SCCT Versus installation. Copy the shared [`_shared`](../_shared) files too. Keep the file names.

## Required installed packages

These come with Enhanced SCCT Versus 3.6 and are not included here:

`Amb_Aqua`, `Amb_Club`, `Amb_Museum`, `Aquarium_STM`, `Aquarium_TXT`, `Armes_impacts`, `CLU04_STM`, `CLU04_TXT`, `Echelon`, `Mall_tibu`, `Missile`, `STM_MALL`, `TXT_ORP`, `TestMapStaticM`, `sfx`, `stm_war`.

Not tested in game.
