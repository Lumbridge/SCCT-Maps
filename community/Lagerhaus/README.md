# Lagerhaus

Community map `Lagerhaus.sdc`, unchanged from the original pack, credits included. Not editable.

Close the game, back up files with the same names, then copy this folder's `Packages` folder into your SCCT Versus installation. Copy the shared [`_shared`](../_shared) files too. Keep the file names.

## Required installed packages

These come with Enhanced SCCT Versus 3.6 and are not included here:

`Amb_Dep`, `Amb_Orph`, `Amb_Tme`, `Amb_factory`, `Aquarium_TXT`, `Armes_impacts`, `BNK_STM`, `CLU04_TXT`, `FAC_TXT`, `GAR_STM`, `Mall_tibu`, `SPersoTextures`, `SPersoTextures_ps2`, `Sound_Persos`, `TME01_STM`, `TXT_ORP`, `TestMapStaticM`, `amb_Bank`, `sfx`, `stm_war`.

Not tested in game.
