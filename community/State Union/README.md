# State Union

Community map `State02.sdc`, unchanged from the original pack, credits included. Not editable.

Close the game, back up files with the same names, then copy this folder's `Packages` folder into your SCCT Versus installation. Copy the shared [`_shared`](../_shared) files too. Keep the file names.

## Required installed packages

These come with Enhanced SCCT Versus 3.6 and are not included here:

`Amb_Aqua`, `Amb_Club`, `Amb_Dep`, `Amb_Miss`, `Amb_factory`, `Aquarium_STM`, `Aquarium_TXT`, `Armes_impacts`, `BNK_STM`, `CLU04_STM`, `CLU04_TXT`, `Echelon`, `GAR_STM`, `Mall_tibu`, `Mall_tibu_stc`, `Missile`, `STM_ORP`, `TXT_MAL`, `TXT_ORP`, `TestMapStaticM`, `stm_war`, `txt_war`.
