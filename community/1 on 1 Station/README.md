# 1 on 1 Station

Community map `G1v1esl.sdc`, unchanged from the original pack, credits included. Not editable.

Close the game, back up files with the same names, then copy this folder's `Packages` and `System` folders into your SCCT Versus installation. Copy the shared [`_shared`](../_shared) files too. Keep the file names.

## Required installed packages

These come with Enhanced SCCT Versus 3.6 and are not included here:

`Amb_Aqua`, `Amb_Club`, `Amb_Gare`, `Amb_Orph`, `Amb_Tme`, `Amb_factory`, `Aquarium_STM`, `Aquarium_TXT`, `Armes_impacts`, `BNK_STM`, `CLU04_STM`, `CLU04_TXT`, `Echelon`, `FAC_STM`, `FAC_TXT`, `GAR_STM`, `GAR_TXT`, `Mall_tibu`, `Mall_tibu_stc`, `SGameplayObjectsTex`, `STM_MALL`, `STM_ORP`, `TME01_STM`, `TXT_BNK`, `TXT_MAL`, `TXT_ORP`, `TestMapStaticM`, `amb_Bank`, `sfx`, `txt_war`.
