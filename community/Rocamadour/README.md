# Rocamadour

Community map `rocamadour.sdc`, unchanged from the original pack, credits included. Not editable.

Close the game, back up files with the same names, then copy this folder's `Packages` folder into your SCCT Versus installation. Copy the shared [`_shared`](../_shared) files too. Keep the file names.

## Required installed packages

These come with Enhanced SCCT Versus 3.6 and are not included here:

`Aquarium_STM`, `Aquarium_TXT`, `Armes_impacts`, `BNK_STM`, `CLU04_STM`, `CLU04_TXT`, `Echelon`, `FAC_TXT`, `GAR_STM`, `Mall_tibu`, `Mall_tibu_stc`, `SGameplayObjectsTex`, `STM_MALL`, `STM_ORP`, `TXT_BNK`, `TXT_MAL`, `TXT_ORP`, `TestMapStaticM`, `sfx`, `stm_war`, `txt_war`.

Not tested in game.
