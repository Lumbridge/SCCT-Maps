# Outpost

Community map `OUT55.sdc`, unchanged from the original pack, credits included. Not editable.

Close the game, back up files with the same names, then copy this folder's `Packages` folder into your SCCT Versus installation. Copy the shared [`_shared`](../_shared) files too. Keep the file names.

## Required installed packages

These come with Enhanced SCCT Versus 3.6 and are not included here:

`Amb_Aqua`, `Amb_Club`, `Amb_Gare`, `Amb_Miss`, `Amb_factory`, `Aquarium_STM`, `Aquarium_TXT`, `BNK_STM`, `CLU04_STM`, `Echelon`, `FAC_STM`, `FAC_TXT`, `GAR_STM`, `GAR_TXT`, `Mall_tibu`, `Missile`, `TXT_BNK`, `TestMapTextures`, `sfx`, `stm_war`, `txt_war`.

Not tested in game.
