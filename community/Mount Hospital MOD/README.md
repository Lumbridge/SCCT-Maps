# Mount Hospital MOD

Community map `MHO05_MOD.sdc`, unchanged from the original pack, credits included. Not editable.

Close the game, back up files with the same names, then copy this folder's `Packages` folder into your SCCT Versus installation. Copy the shared [`_shared`](../_shared) files too. Keep the file names.

## Required installed packages

These come with Enhanced SCCT Versus 3.6 and are not included here:

`Amb_Aqua`, `Amb_Club`, `Amb_Miss`, `Amb_Orph`, `Aquarium_STM`, `Aquarium_TXT`, `CLU04_STM`, `CLU04_TXT`, `Echelon`, `FAC_TXT`, `Mall_tibu`, `Missile`, `SGameplayObjectsTex`, `STM_MALL`, `TXT_MAL`, `TXT_ORP`, `TestMapStaticM`, `amb_Bank`, `sfx`, `stm_war`.

Not tested in game.
