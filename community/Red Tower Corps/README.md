# Red Tower Corps.

Community map `tower1.sdc`, unchanged from the original pack, credits included. Not editable.

Close the game, back up files with the same names, then copy this folder's `Packages` folder into your SCCT Versus installation. Copy the shared [`_shared`](../_shared) files too. Keep the file names.

## Required installed packages

These come with Enhanced SCCT Versus 3.6 and are not included here:

`Amb_Aqua`, `Amb_Club`, `Amb_Gare`, `Amb_Miss`, `Aquarium_STM`, `Aquarium_TXT`, `Armes_impacts`, `BNK_STM`, `CLU04_STM`, `CLU04_TXT`, `Echelon`, `FAC_STM`, `FAC_TXT`, `GAR_STM`, `GAR_TXT`, `Mall_tibu`, `Mall_tibu_stc`, `Missile`, `STM_MALL`, `STM_ORP`, `TXT_BNK`, `TXT_MAL`, `TXT_ORP`, `sfx`.

Not tested in game.
