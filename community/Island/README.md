# Island

Community map `new-island.sdc`, unchanged from the original pack, credits included. Not editable.

Close the game, back up files with the same names, then copy this folder's `Packages` folder into your SCCT Versus installation. Copy the shared [`_shared`](../_shared) files too. Keep the file names.

## Required installed packages

These come with Enhanced SCCT Versus 3.6 and are not included here:

`Amb_Aqua`, `Amb_Club`, `Aquarium_STM`, `Aquarium_TXT`, `Armes_impacts`, `CLU04_STM`, `CLU04_TXT`, `GAR_STM`, `Interface`, `Missile`, `sfx`, `stm_war`.

Not tested in game.

Known issue: Island has no title or picture on the map-selection screen.
