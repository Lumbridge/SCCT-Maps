# Dock

Community map `DOC14.sdc`, unchanged from the original pack, credits included. Not editable.

Close the game, back up files with the same names, then copy this folder's `Packages` folder into your SCCT Versus installation. Copy the shared [`_shared`](../_shared) files too. Keep the file names.

## Required installed packages

These come with Enhanced SCCT Versus 3.6 and are not included here:

`Amb_Aqua`, `Amb_Dep`, `Amb_Gare`, `Amb_factory`, `Aquarium_STM`, `Aquarium_TXT`, `Armes_impacts`, `BNK_STM`, `FAC_STM`, `FAC_TXT`, `GAR_STM`, `GAR_TXT`, `Interface`, `Mall_tibu_stc`, `Missile`, `TXT_BNK`, `TestMapStaticM`, `amb_Bank`, `sfx`, `stm_war`.
