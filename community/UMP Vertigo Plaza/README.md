# UMP Vertigo Plaza

Community map `SKY08.sdc`, unchanged from the original pack, credits included. Not editable.

Close the game, back up files with the same names, then copy this folder's `Packages` folder into your SCCT Versus installation. Copy the shared [`_shared`](../_shared) files too. Keep the file names.

## Required installed packages

These come with Enhanced SCCT Versus 3.6 and are not included here:

`Amb_Aqua`, `Amb_Club`, `Amb_Gare`, `Amb_Miss`, `Amb_Museum`, `Amb_Orph`, `Amb_factory`, `Aquarium_STM`, `Aquarium_TXT`, `Armes_impacts`, `BNK_STM`, `CLU04_STM`, `CLU04_TXT`, `Echelon`, `FAC_STM`, `GAR_TXT`, `Missile`, `SEffectStatic`, `SGameplayObjectsTex`, `STM_MALL`, `STM_ORP`, `Sound_Persos`, `TXT_MAL`, `TXT_ORP`, `TestMapStaticM`, `sfx`.

Not tested in game.

## Known issue

The pack has two different `SKY08-i.utc` files, one in `Packages/StaticMeshes` and one in `Packages/Textures`. Both are kept where they were. Which one the game loads has not been tested.
