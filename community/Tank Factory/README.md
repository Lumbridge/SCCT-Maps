# Tank Factory

Community map `TAF06.sdc`, unchanged from the original pack, credits included. Not editable.

Close the game, back up files with the same names, then copy this folder's `Packages` folder into your SCCT Versus installation. Copy the shared [`_shared`](../_shared) files too. Keep the file names.

## Required installed packages

These come with Enhanced SCCT Versus 3.6 and are not included here:

`Amb_Aqua`, `Amb_Dep`, `Amb_Gare`, `Amb_Miss`, `Amb_Orph`, `Amb_factory`, `Aquarium_STM`, `Aquarium_TXT`, `Armes_impacts`, `Echelon`, `FAC_STM`, `FAC_TXT`, `GAR_STM`, `GAR_TXT`, `Mall_tibu`, `Mall_tibu_stc`, `Missile`, `STM_MALL`, `STM_ORP`, `TXT_ORP`, `sfx`, `stm_war`, `txt_war`.

Not tested in game.
