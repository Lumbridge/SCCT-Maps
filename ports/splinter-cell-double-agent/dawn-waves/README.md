# Dawn Waves (SCDA_DWG) from Splinter Cell: Double Agent

The Splinter Cell: Double Agent (PC) map **Dawn Waves** (`DWG`), ported to Enhanced SCCT Versus 3.6.

## Install

Close the game and the editor, back up files with the same names, then copy the files into your Enhanced SCCT Versus 3.6 installation:

| File | Goes to |
| --- | --- |
| `SCDA_DWG-Playable.sdc` | `Packages/Maps/SCDA_DWG.sdc` |
| `SCDA_DWG-Editable.sdc` | `Packages/MapsEd/SCDA_DWG.sdc` |
| `SCDA_DWG-i.utc` | `Packages/Textures/SCDA_DWG-i.utc` |
| `SCDA_DWG_VS.usx` | `Packages/StaticMeshes/SCDA_DWG_VS.usx` |

Playable map: `Packages/Maps/SCDA_DWG.sdc`. Editable map: `Packages/MapsEd/SCDA_DWG.sdc` (open it in the [Reloaded Editor](https://github.com/Lumbridge/SCCT_Versus_Reloaded_Editor)).

Both maps need `SCDA_DWG_VS.usx` (meshes and materials, 29.9 MB) and no other package. Other players need the same files to join you.

## Known issues

- Converted meshes and materials. Check collision, materials, lighting and gameplay before building on it.
- Not playtested in game.
- The map-settings file is bare. See the [collection notes](../README.md).
