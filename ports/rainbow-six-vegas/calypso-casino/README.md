# Calypso Casino (CalyD) from Rainbow Six Vegas

The Calypso Casino map from Rainbow Six Vegas (PC), ported to Enhanced SCCT Versus 3.6. The release has the playable and editable `CalyD.sdc` maps, the map-selection lightmap, and the Calypso mesh and material packages the map needs.

Download the current CalyD release from the repository Releases page. Close the game and editor, back up existing files, then copy the package files into your Enhanced SCCT Versus 3.6 installation.

- Playable map: `Packages/Maps/CalyD.sdc`
- Editable map: `Packages/MapsEd/CalyD.sdc` (open it in the Reloaded Editor)

Known issue: the assets and materials are converted. Check collision, materials, lighting and gameplay before using it in a published map.
