# Calypso Casino (CalyD) — Rainbow Six Vegas

Ported from the Rainbow Six Vegas PC Calypso Casino map into Enhanced SCCT Versus 3.6. The release assets include playable and editable `CalyD.sdc` maps, the map-selection lightmap, and the Calypso mesh and material packages required by the port.

Download the current CalyD release from the repository Releases page. Close the game and editor, back up existing files, then copy the package files into your Enhanced SCCT Versus 3.6 installation. Open `Packages/MapsEd/CalyD.sdc` in the Reloaded Editor. The playable map is `Packages/Maps/CalyD.sdc`.

The source game is Rainbow Six Vegas for PC. The port uses converted assets and SCCT-compatible materials; review collision, materials, lighting, and gameplay before using it in a published map.
