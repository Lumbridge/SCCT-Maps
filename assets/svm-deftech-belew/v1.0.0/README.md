# SCCT Versus - Deftech Belew assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to Deftech Belew (`DeftD`, `DeftS`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `DTK_SPECIFIC_MESH.usx` | `Packages/StaticMeshes` | 11 static meshes |
| `DTK_STATICMESHS_TC.usx` | `Packages/StaticMeshes` | 131 static meshes |
| `DeftD-i.utc` | `Packages/Textures` | Map-selection image for `DeftD` |
| `DeftS-i.utc` | `Packages/Textures` | Map-selection image for `DeftS` |
| `DTK_TEXTURES_TC.utx` | `Packages/Textures` | 94 textures, 42 materials |
| `DTK_XBOX.utx` | `Packages/Textures` | 18 textures, 2 materials |
| `SFX_DTK_xbox.utx` | `Packages/Textures` | 2 textures |
| `SGPOTexE.utx` | `Packages/Textures` | 2 textures |
| `SGPOTexE_led.utx` | `Packages/Textures` | 2 materials |
| `amb_Belew.uax` | `Packages/Sounds` | 38 sounds |
| `DeftD.uas` | `Packages/Sounds` | Sound list for `DeftD` |
| `DeftS.uas` | `Packages/Sounds` | Sound list for `DeftS` |
| `MC_dtk_ext.mux` | `Packages/Sounds` | Ambient sound stream |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-deftech-belew-v1.0.0).
