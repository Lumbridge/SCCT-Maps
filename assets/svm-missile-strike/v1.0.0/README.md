# SCCT Versus - Missile Strike assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to Missile Strike (`MissD`, `MissE`, `MissP`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `Missile.usx` | `Packages/StaticMeshes` | 210 static meshes |
| `STM_MER.usx` | `Packages/StaticMeshes` | 57 static meshes |
| `MissD-i.utc` | `Packages/Textures` | Map-selection image for `MissD` |
| `MissE-i.utc` | `Packages/Textures` | Map-selection image for `MissE` |
| `MissP-i.utc` | `Packages/Textures` | Map-selection image for `MissP` |
| `TXT_MER.utx` | `Packages/Textures` | 120 textures, 31 materials |
| `MIS_ANM.ukx` | `Packages/Animations` | 5 skeletal meshes, 5 animation sets |
| `Amb_Miss.uax` | `Packages/Sounds` | 69 sounds |
| `MC_mis_ext_mer1.mux` | `Packages/Sounds` | Ambient sound stream |
| `MissD.uas` | `Packages/Sounds` | Sound list for `MissD` |
| `MissE.uas` | `Packages/Sounds` | Sound list for `MissE` |
| `MissP.uas` | `Packages/Sounds` | Sound list for `MissP` |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md), [Shared props](../../svm-shared-props/v1.0.0/README.md), [Cinema](../../svm-cinema/v1.0.0/README.md), [Mount Hospital](../../svm-mount-hospital/v1.0.0/README.md), [Skyscraper](../../svm-skyscraper/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-missile-strike-v1.0.0).
