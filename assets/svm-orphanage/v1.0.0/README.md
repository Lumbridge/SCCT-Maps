# SCCT Versus - Orphanage assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to Orphanage (`OrphD`, `OrphE`, `OrphS`, `OrphT`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `STM_ORP.usx` | `Packages/StaticMeshes` | 170 static meshes |
| `OrphD-i.utc` | `Packages/Textures` | Map-selection image for `OrphD` |
| `OrphE-i.utc` | `Packages/Textures` | Map-selection image for `OrphE` |
| `OrphS-i.utc` | `Packages/Textures` | Map-selection image for `OrphS` |
| `OrphT-i.utc` | `Packages/Textures` | Map-selection image for `OrphT` |
| `TXT_ORP.utx` | `Packages/Textures` | 71 textures, 23 materials |
| `orf_anm.ukx` | `Packages/Animations` | 4 skeletal meshes, 4 animation sets |
| `Amb_Orph.uax` | `Packages/Sounds` | 66 sounds |
| `MC_Explo_Groupe_Serre.mux` | `Packages/Sounds` | Ambient sound stream |
| `MC_orph_explo_groupe.mux` | `Packages/Sounds` | Ambient sound stream |
| `MC_orph_explo_plancher.mux` | `Packages/Sounds` | Ambient sound stream |
| `MC_orph_ext_cour.mux` | `Packages/Sounds` | Ambient sound stream |
| `MC_orph_ext_jardin.mux` | `Packages/Sounds` | Ambient sound stream |
| `OrphD.uas` | `Packages/Sounds` | Sound list for `OrphD` |
| `OrphE.uas` | `Packages/Sounds` | Sound list for `OrphE` |
| `OrphS.uas` | `Packages/Sounds` | Sound list for `OrphS` |
| `OrphT.uas` | `Packages/Sounds` | Sound list for `OrphT` |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md), [Deftech Belew](../../svm-deftech-belew/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-orphanage-v1.0.0).
