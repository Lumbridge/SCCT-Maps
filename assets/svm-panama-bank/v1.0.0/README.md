# SCCT Versus - Panama Bank assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to Panama Bank (`PanaD`, `PanaS`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `panama.usx` | `Packages/StaticMeshes` | 101 static meshes |
| `PanaD-i.utc` | `Packages/Textures` | Map-selection image for `PanaD` |
| `Panama_TXT.utx` | `Packages/Textures` | 50 textures |
| `PanaS-i.utc` | `Packages/Textures` | Map-selection image for `PanaS` |
| `amb_panama02.uax` | `Packages/Sounds` | 22 sounds |
| `PanaD.uas` | `Packages/Sounds` | Sound list for `PanaD` |
| `PanaS.uas` | `Packages/Sounds` | Sound list for `PanaS` |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md), [Shared props](../../svm-shared-props/v1.0.0/README.md), [Aquarius](../../svm-aquarius/v1.0.0/README.md), [Bank](../../svm-bank/v1.0.0/README.md), [Club House](../../svm-club-house/v1.0.0/README.md), [Deftech Belew](../../svm-deftech-belew/v1.0.0/README.md), [Krauser Lab](../../svm-krauser-lab/v1.0.0/README.md), [Orphanage](../../svm-orphanage/v1.0.0/README.md), [River Mall](../../svm-river-mall/v1.0.0/README.md), [Warehouse](../../svm-warehouse/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-panama-bank-v1.0.0).
