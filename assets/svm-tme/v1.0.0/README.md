# SCCT Versus - TME30-33 assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to TME30-33 (`TME30`, `TME32`, `TME33`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `TME01_STM.usx` | `Packages/StaticMeshes` | 71 static meshes |
| `TME01_TXT.utx` | `Packages/Textures` | 131 textures, 60 materials |
| `TME30-i.utc` | `Packages/Textures` | Map-selection image for `TME30` |
| `TME32-i.utc` | `Packages/Textures` | Map-selection image for `TME32` |
| `TME33-i.utc` | `Packages/Textures` | Map-selection image for `TME33` |
| `TME01_anm.ukx` | `Packages/Animations` | 7 skeletal meshes, 7 animation sets |
| `Amb_Tme.uax` | `Packages/Sounds` | 26 sounds |
| `MC_tme_exploMur.mux` | `Packages/Sounds` | Ambient sound stream |
| `TME30.uas` | `Packages/Sounds` | Sound list for `TME30` |
| `TME32.uas` | `Packages/Sounds` | Sound list for `TME32` |
| `TME33.uas` | `Packages/Sounds` | Sound list for `TME33` |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-tme-v1.0.0).
