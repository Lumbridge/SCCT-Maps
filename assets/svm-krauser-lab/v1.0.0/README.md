# SCCT Versus - Krauser Lab assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to Krauser Lab (`KrauE`, `KrauU`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `KRA07_Dedouble.usx` | `Packages/StaticMeshes` | 30 static meshes |
| `KRA07_NEW.usx` | `Packages/StaticMeshes` | 3 static meshes |
| `KRA07_Specifik_XBox.usx` | `Packages/StaticMeshes` | 6 static meshes |
| `krauser_stm.usx` | `Packages/StaticMeshes` | 133 static meshes |
| `KrauE-i.utc` | `Packages/Textures` | Map-selection image for `KrauE` |
| `krauser_txt.utx` | `Packages/Textures` | 92 textures, 20 materials |
| `krauser_txt_XBOX.utx` | `Packages/Textures` | 11 textures, 1 material |
| `KrauU-i.utc` | `Packages/Textures` | Map-selection image for `KrauU` |
| `SFX_KRA_xbox.utx` | `Packages/Textures` | 28 textures, 19 materials |
| `Amb_Krauser.uax` | `Packages/Sounds` | 38 sounds |
| `KrauE.uas` | `Packages/Sounds` | Sound list for `KrauE` |
| `KrauU.uas` | `Packages/Sounds` | Sound list for `KrauU` |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md), [Aquarius](../../svm-aquarius/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-krauser-lab-v1.0.0).
