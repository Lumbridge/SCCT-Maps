# SCCT Versus - Terminus assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to Terminus (`TermD`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `Terminus_STM.usx` | `Packages/StaticMeshes` | 407 static meshes |
| `TermD-i.utc` | `Packages/Textures` | Map-selection image for `TermD` |
| `Terminus_TXT.utx` | `Packages/Textures` | 328 textures, 55 materials |
| `Amb_Terminus.uax` | `Packages/Sounds` | 18 sounds |
| `TermD.uas` | `Packages/Sounds` | Sound list for `TermD` |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md), [Factory](../../svm-factory/v1.0.0/README.md), [Station](../../svm-station/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-terminus-v1.0.0).
