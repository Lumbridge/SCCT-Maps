# SCCT Versus - Shared props assets v1.0.0

Props, textures and ambient sounds from the SCCT Versus 4.0 install that several maps share and no single map owns. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `chantier_poc.usx` | `Packages/StaticMeshes` | 172 static meshes |
| `chantier_poc_stm.usx` | `Packages/StaticMeshes` | 72 static meshes |
| `CTF_static.usx` | `Packages/StaticMeshes` | 1 static mesh |
| `SM_Reactor.usx` | `Packages/StaticMeshes` | 8 static meshes |
| `Bunker.utx` | `Packages/Textures` | 101 textures, 47 materials |
| `drpoc_chantier.utx` | `Packages/Textures` | 55 textures, 32 materials |
| `drpoc_chantier_XBOX.utx` | `Packages/Textures` | 46 textures, 21 materials |
| `nd133.utx` | `Packages/Textures` | 7 textures, 10 materials |
| `nd133_1mesh.ukx` | `Packages/Animations` | 1 skeletal mesh, 1 animation set |
| `nd133_anm.ukx` | `Packages/Animations` | 4 skeletal meshes, 4 animation sets |
| `Scam_cine.ukx` | `Packages/Animations` | 1 skeletal mesh, 1 animation set |
| `Amb_Building.uax` | `Packages/Sounds` | 23 sounds |
| `amb_Com.uax` | `Packages/Sounds` | 19 sounds |
| `Amb_Dep.uax` | `Packages/Sounds` | 16 sounds |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md), [TME30-33](../../svm-tme/v1.0.0/README.md), [Warehouse](../../svm-warehouse/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-shared-props-v1.0.0).
