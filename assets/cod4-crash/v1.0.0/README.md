# Call of Duty 4 - Crash assets v1.0.0

Static meshes and textures from the Call of Duty 4 multiplayer map Crash (`mp_crash`), for your own SCCT maps. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `COD4_crash.usx` | `Packages/StaticMeshes` | 522 static meshes (source props and leftover world geometry) with embedded materials |
| `COD4_crash_TXT.utx` | `Packages/Textures` | 315 textures, 311 materials |

The texture package has exact copies of the materials in the mesh package. Use it to texture your own BSP or meshes. Maps that use it must ship that `.utx`. The [editable BSP port](../../../ports/call-of-duty-4/crash/README.md) uses the same mesh package.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/cod4-crash-v1.0.0).
