# SCCT Versus - Cinema assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to Cinema (`CineE`, `CineS`, `CineU`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `STM_INI.usx` | `Packages/StaticMeshes` | 89 static meshes |
| `CineE-i.utc` | `Packages/Textures` | Map-selection image for `CineE` |
| `CineS-i.utc` | `Packages/Textures` | Map-selection image for `CineS` |
| `CineU-i.utc` | `Packages/Textures` | Map-selection image for `CineU` |
| `TXT_INI.utx` | `Packages/Textures` | 82 textures, 57 materials |
| `Amb_Ini.uax` | `Packages/Sounds` | 18 sounds |
| `CineE.uas` | `Packages/Sounds` | Sound list for `CineE` |
| `CineS.uas` | `Packages/Sounds` | Sound list for `CineS` |
| `CineU.uas` | `Packages/Sounds` | Sound list for `CineU` |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md), [Station](../../svm-station/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-cinema-v1.0.0).
