# SCCT Versus - Pyrocryptic assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to Pyrocryptic (`PyroD`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `crypt01_sm.usx` | `Packages/StaticMeshes` | 89 static meshes |
| `crypt_txt.utx` | `Packages/Textures` | 37 textures, 5 materials |
| `PyroD-i.utc` | `Packages/Textures` | Map-selection image for `PyroD` |
| `PyroD.uas` | `Packages/Sounds` | Sound list for `PyroD` |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md), [Shared props](../../svm-shared-props/v1.0.0/README.md), [Aquarius](../../svm-aquarius/v1.0.0/README.md), [Club House](../../svm-club-house/v1.0.0/README.md), [Orphanage](../../svm-orphanage/v1.0.0/README.md), [River Mall](../../svm-river-mall/v1.0.0/README.md), [Warehouse](../../svm-warehouse/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-pyrocryptic-v1.0.0).
