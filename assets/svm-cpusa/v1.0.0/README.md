# SCCT Versus - Cpusa assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to Cpusa (`CpusS`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `PCF09_STM.usx` | `Packages/StaticMeshes` | 189 static meshes |
| `CpusS-i.utc` | `Packages/Textures` | Map-selection image for `CpusS` |
| `PCF09_TXT.utx` | `Packages/Textures` | 248 textures, 87 materials |
| `CpusS.uas` | `Packages/Sounds` | Sound list for `CpusS` |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md), [Shared props](../../svm-shared-props/v1.0.0/README.md), [Aquarius](../../svm-aquarius/v1.0.0/README.md), [Bank](../../svm-bank/v1.0.0/README.md), [Club House](../../svm-club-house/v1.0.0/README.md), [Deftech Belew](../../svm-deftech-belew/v1.0.0/README.md), [River Mall](../../svm-river-mall/v1.0.0/README.md), [Station](../../svm-station/v1.0.0/README.md), [Steel Squat](../../svm-steel-squat/v1.0.0/README.md), [TME30-33](../../svm-tme/v1.0.0/README.md), [TSP20-29](../../svm-tsp/v1.0.0/README.md), [Warehouse](../../svm-warehouse/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-cpusa-v1.0.0).
