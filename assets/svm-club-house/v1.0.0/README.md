# SCCT Versus - Club House assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to Club House (`ClubD`, `ClubE`, `ClubS`, `ClubT`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `CLU04_STM.usx` | `Packages/StaticMeshes` | 157 static meshes |
| `ECH_STM.usx` | `Packages/StaticMeshes` | 3 static meshes |
| `CLU04_TXT.utx` | `Packages/Textures` | 140 textures, 92 materials |
| `ClubD-i.utc` | `Packages/Textures` | Map-selection image for `ClubD` |
| `ClubE-i.utc` | `Packages/Textures` | Map-selection image for `ClubE` |
| `ClubS-i.utc` | `Packages/Textures` | Map-selection image for `ClubS` |
| `ClubT-i.utc` | `Packages/Textures` | Map-selection image for `ClubT` |
| `CLU_anims.ukx` | `Packages/Animations` | 10 skeletal meshes, 10 animation sets |
| `Amb_Club.uax` | `Packages/Sounds` | 76 sounds |
| `ClubD.uas` | `Packages/Sounds` | Sound list for `ClubD` |
| `ClubE.uas` | `Packages/Sounds` | Sound list for `ClubE` |
| `ClubS.uas` | `Packages/Sounds` | Sound list for `ClubS` |
| `ClubT.uas` | `Packages/Sounds` | Sound list for `ClubT` |
| `MC_clu_ext.mux` | `Packages/Sounds` | Ambient sound stream |
| `MC_clu_OpenVerriere_Air.mux` | `Packages/Sounds` | Ambient sound stream |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md), [Deftech Belew](../../svm-deftech-belew/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-club-house-v1.0.0).
