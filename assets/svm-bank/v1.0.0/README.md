# SCCT Versus - Bank assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to Bank (`BankD`, `BankP`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `BNK_STM.usx` | `Packages/StaticMeshes` | 148 static meshes |
| `BankD-i.utc` | `Packages/Textures` | Map-selection image for `BankD` |
| `BankP-i.utc` | `Packages/Textures` | Map-selection image for `BankP` |
| `TXT_BNK.utx` | `Packages/Textures` | 135 textures, 114 materials |
| `amb_Bank.uax` | `Packages/Sounds` | 22 sounds |
| `BankD.uas` | `Packages/Sounds` | Sound list for `BankD` |
| `BankP.uas` | `Packages/Sounds` | Sound list for `BankP` |
| `MC_bnk_helico.mux` | `Packages/Sounds` | Ambient sound stream |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-bank-v1.0.0).
