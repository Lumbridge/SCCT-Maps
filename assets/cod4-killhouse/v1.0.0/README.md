# Call of Duty 4 - Killhouse assets v1.0.0

Static meshes and textures from the Call of Duty 4 multiplayer map Killhouse (`mp_killhouse`), for your own SCCT maps. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `COD4_killhouse.usx` | `Packages/StaticMeshes` | 896 static meshes (source props and leftover world geometry) with embedded materials |
| `COD4_killhouse_TXT.utx` | `Packages/Textures` | 211 textures, 208 materials |

The texture package has exact copies of the materials in the mesh package. Use it to texture your own BSP or meshes. Maps that use it must ship that `.utx`. The [editable BSP port](../../../ports/call-of-duty-4/killhouse/README.md) uses the same mesh package.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/cod4-killhouse-v1.0.0).
