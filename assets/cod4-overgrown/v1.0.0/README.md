# Call of Duty 4 - Overgrown assets v1.0.0

Static meshes and textures from the Call of Duty 4 multiplayer map Overgrown (`mp_overgrown`), for your own SCCT maps. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `COD4_overgrown.usx` | `Packages/StaticMeshes` | 914 static meshes (source props and leftover world geometry) with embedded materials |
| `COD4_overgrown_TXT.utx` | `Packages/Textures` | 254 textures, 243 materials |

The texture package has exact copies of the materials in the mesh package. Use it to texture your own BSP or meshes. Maps that use it must ship that `.utx`. The [editable BSP port](../../../ports/call-of-duty-4/overgrown/README.md) uses the same mesh package.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/cod4-overgrown-v1.0.0).
