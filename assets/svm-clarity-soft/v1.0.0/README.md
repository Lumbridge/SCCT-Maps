# SCCT Versus - Clarity Soft assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to Clarity Soft (`ClarD`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `Poly.usx` | `Packages/StaticMeshes` | 3 static meshes |
| `ClarD-i.utc` | `Packages/Textures` | Map-selection image for `ClarD` |
| `claritysoft.utx` | `Packages/Textures` | 20 textures, 12 materials |
| `ClarD.uas` | `Packages/Sounds` | Sound list for `ClarD` |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md), [Shared props](../../svm-shared-props/v1.0.0/README.md), [Aquarius](../../svm-aquarius/v1.0.0/README.md), [Cinema](../../svm-cinema/v1.0.0/README.md), [Skyscraper](../../svm-skyscraper/v1.0.0/README.md), [Station](../../svm-station/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-clarity-soft-v1.0.0).
