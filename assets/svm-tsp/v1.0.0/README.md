# SCCT Versus - TSP20-29 assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to TSP20-29 (`TSP20`, `TSP21`, `TSP22`, `TSP23`, `TSP29`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `TSP01_STM.usx` | `Packages/StaticMeshes` | 98 static meshes |
| `TSP01_TXT.utx` | `Packages/Textures` | 94 textures, 61 materials |
| `TSP20-i.utc` | `Packages/Textures` | Map-selection image for `TSP20` |
| `TSP21-i.utc` | `Packages/Textures` | Map-selection image for `TSP21` |
| `TSP22-i.utc` | `Packages/Textures` | Map-selection image for `TSP22` |
| `TSP23-i.utc` | `Packages/Textures` | Map-selection image for `TSP23` |
| `TSP29-i.utc` | `Packages/Textures` | Map-selection image for `TSP29` |
| `TSP01_anm.ukx` | `Packages/Animations` | 7 skeletal meshes, 6 animation sets |
| `Amb_Tsp.uax` | `Packages/Sounds` | 26 sounds |
| `TSP20.uas` | `Packages/Sounds` | Sound list for `TSP20` |
| `TSP21.uas` | `Packages/Sounds` | Sound list for `TSP21` |
| `TSP22.uas` | `Packages/Sounds` | Sound list for `TSP22` |
| `TSP23.uas` | `Packages/Sounds` | Sound list for `TSP23` |
| `TSP29.uas` | `Packages/Sounds` | Sound list for `TSP29` |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-tsp-v1.0.0).
