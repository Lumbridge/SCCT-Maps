# SCCT Versus - Sanctuary assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to Sanctuary (`SancD`, `SancE`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `CHU01_SM.usx` | `Packages/StaticMeshes` | 60 static meshes |
| `ESA20_STM.usx` | `Packages/StaticMeshes` | 1 static mesh |
| `CHU01_TXT.utx` | `Packages/Textures` | 15 textures, 2 materials |
| `ESA20_TXT.utx` | `Packages/Textures` | 8 textures |
| `SancD-i.utc` | `Packages/Textures` | Map-selection image for `SancD` |
| `SancE-i.utc` | `Packages/Textures` | Map-selection image for `SancE` |
| `SancD.uas` | `Packages/Sounds` | Sound list for `SancD` |
| `SancE.uas` | `Packages/Sounds` | Sound list for `SancE` |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md), [Shared props](../../svm-shared-props/v1.0.0/README.md), [Aquarius](../../svm-aquarius/v1.0.0/README.md), [Bank](../../svm-bank/v1.0.0/README.md), [Deftech Belew](../../svm-deftech-belew/v1.0.0/README.md), [Orphanage](../../svm-orphanage/v1.0.0/README.md), [Steel Squat](../../svm-steel-squat/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-sanctuary-v1.0.0).
