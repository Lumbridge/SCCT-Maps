# SCCT Versus - Vertigo Plaza assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to Vertigo Plaza (`VertE`, `VertU`, `VertX`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `EVP_STM.usx` | `Packages/StaticMeshes` | 2 static meshes |
| `SKYMZ1-i.utc` | `Packages/Textures` | Map-selection image for `SKYMZ1` |
| `VertE-i.utc` | `Packages/Textures` | Map-selection image for `VertE` |
| `VertU-i.utc` | `Packages/Textures` | Map-selection image for `VertU` |
| `VertX-i.utc` | `Packages/Textures` | Map-selection image for `VertX` |
| `VertE.uas` | `Packages/Sounds` | Sound list for `VertE` |
| `VertU.uas` | `Packages/Sounds` | Sound list for `VertU` |
| `VertX.uas` | `Packages/Sounds` | Sound list for `VertX` |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md), [Shared props](../../svm-shared-props/v1.0.0/README.md), [Skyscraper](../../svm-skyscraper/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-vertigo-plaza-v1.0.0).
