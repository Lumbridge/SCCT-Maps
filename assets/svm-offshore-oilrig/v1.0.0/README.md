# SCCT Versus - Offshore Oilrig assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to Offshore Oilrig (`OffsD`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `Oilrig_SM.usx` | `Packages/StaticMeshes` | 30 static meshes |
| `OffsD-i.utc` | `Packages/Textures` | Map-selection image for `OffsD` |
| `Oilrig_TXT.utx` | `Packages/Textures` | 20 textures |
| `OffsD.uas` | `Packages/Sounds` | Sound list for `OffsD` |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md), [Shared props](../../svm-shared-props/v1.0.0/README.md), [Deftech Belew](../../svm-deftech-belew/v1.0.0/README.md), [Factory](../../svm-factory/v1.0.0/README.md), [Station](../../svm-station/v1.0.0/README.md), [Warehouse](../../svm-warehouse/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-offshore-oilrig-v1.0.0).
