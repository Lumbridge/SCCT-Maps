# SCCT Versus - Zioplex assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to Zioplex (`ZiopD`, `ZiopS`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `Lev01_sm.usx` | `Packages/StaticMeshes` | 49 static meshes |
| `ZCT_TX.utx` | `Packages/Textures` | 54 textures, 3 materials |
| `ZiopD-i.utc` | `Packages/Textures` | Map-selection image for `ZiopD` |
| `ZiopS-i.utc` | `Packages/Textures` | Map-selection image for `ZiopS` |
| `ZiopD.uas` | `Packages/Sounds` | Sound list for `ZiopD` |
| `ZiopS.uas` | `Packages/Sounds` | Sound list for `ZiopS` |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md), [Shared props](../../svm-shared-props/v1.0.0/README.md), [Aquarius](../../svm-aquarius/v1.0.0/README.md), [Deftech Belew](../../svm-deftech-belew/v1.0.0/README.md), [Krauser Lab](../../svm-krauser-lab/v1.0.0/README.md), [Skyscraper](../../svm-skyscraper/v1.0.0/README.md), [Station](../../svm-station/v1.0.0/README.md), [Warehouse](../../svm-warehouse/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-zioplex-v1.0.0).
