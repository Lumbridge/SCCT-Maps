# SCCT Versus - Aquarius assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to Aquarius (`AquaD`, `AquaE`, `AquaT`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `Aquarium_STM.usx` | `Packages/StaticMeshes` | 190 static meshes |
| `EAQ_STM.usx` | `Packages/StaticMeshes` | 1 static mesh |
| `STM_Poc_AquaTest.usx` | `Packages/StaticMeshes` | 19 static meshes |
| `AquaD-i.utc` | `Packages/Textures` | Map-selection image for `AquaD` |
| `AquaE-i.utc` | `Packages/Textures` | Map-selection image for `AquaE` |
| `Aquarium_TXT.utx` | `Packages/Textures` | 220 textures, 72 materials |
| `AquaT-i.utc` | `Packages/Textures` | Map-selection image for `AquaT` |
| `AQU_anm.ukx` | `Packages/Animations` | 9 skeletal meshes, 9 animation sets |
| `Amb_Aqua.uax` | `Packages/Sounds` | 79 sounds |
| `AquaD.uas` | `Packages/Sounds` | Sound list for `AquaD` |
| `AquaE.uas` | `Packages/Sounds` | Sound list for `AquaE` |
| `AquaT.uas` | `Packages/Sounds` | Sound list for `AquaT` |
| `MC_aquaExt.mux` | `Packages/Sounds` | Ambient sound stream |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-aquarius-v1.0.0).
