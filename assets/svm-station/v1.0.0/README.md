# SCCT Versus - Station assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to Station (`StatD`, `StatE`, `StatS`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `EST_STM.usx` | `Packages/StaticMeshes` | 2 static meshes |
| `GAR_STM.usx` | `Packages/StaticMeshes` | 120 static meshes |
| `EST_TXT.utx` | `Packages/Textures` | 2 textures, 2 materials |
| `GAR_TXT.utx` | `Packages/Textures` | 128 textures, 76 materials |
| `StatD-i.utc` | `Packages/Textures` | Map-selection image for `StatD` |
| `StatE-i.utc` | `Packages/Textures` | Map-selection image for `StatE` |
| `StatS-i.utc` | `Packages/Textures` | Map-selection image for `StatS` |
| `GAR_anm.ukx` | `Packages/Animations` | 5 skeletal meshes, 5 animation sets |
| `Amb_Gare.uax` | `Packages/Sounds` | 45 sounds |
| `MC_gare_ambExt.mux` | `Packages/Sounds` | Ambient sound stream |
| `MC_gare_train.mux` | `Packages/Sounds` | Ambient sound stream |
| `StatD.uas` | `Packages/Sounds` | Sound list for `StatD` |
| `StatE.uas` | `Packages/Sounds` | Sound list for `StatE` |
| `StatS.uas` | `Packages/Sounds` | Sound list for `StatS` |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-station-v1.0.0).
