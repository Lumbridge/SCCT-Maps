# SCCT Versus - Slaughterhouse assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to Slaughterhouse (`SlauS`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `SLH07_STM.usx` | `Packages/StaticMeshes` | 26 static meshes |
| `SlauS-i.utc` | `Packages/Textures` | Map-selection image for `SlauS` |
| `SLH07_TXT.utx` | `Packages/Textures` | 43 textures |
| `SlauS.uas` | `Packages/Sounds` | Sound list for `SlauS` |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md), [Factory](../../svm-factory/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-slaughterhouse-v1.0.0).
