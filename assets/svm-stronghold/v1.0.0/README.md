# SCCT Versus - Stronghold assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to Stronghold (`StroD`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `Island.usx` | `Packages/StaticMeshes` | 30 static meshes, 78 textures |
| `STRH_meshes.usx` | `Packages/StaticMeshes` | 56 static meshes |
| `STRH_txt.utx` | `Packages/Textures` | 8 textures |
| `StroD-i.utc` | `Packages/Textures` | Map-selection image for `StroD` |
| `Amb_Stronghold.uax` | `Packages/Sounds` | 5 sounds |
| `StroD.uas` | `Packages/Sounds` | Sound list for `StroD` |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md), [Shared props](../../svm-shared-props/v1.0.0/README.md), [Aquarius](../../svm-aquarius/v1.0.0/README.md), [Bank](../../svm-bank/v1.0.0/README.md), [Club House](../../svm-club-house/v1.0.0/README.md), [Factory](../../svm-factory/v1.0.0/README.md), [Orphanage](../../svm-orphanage/v1.0.0/README.md), [Panama Bank](../../svm-panama-bank/v1.0.0/README.md), [Pyrocryptic](../../svm-pyrocryptic/v1.0.0/README.md), [River Mall](../../svm-river-mall/v1.0.0/README.md), [Skyscraper](../../svm-skyscraper/v1.0.0/README.md), [Steel Squat](../../svm-steel-squat/v1.0.0/README.md), [Warehouse](../../svm-warehouse/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-stronghold-v1.0.0).
