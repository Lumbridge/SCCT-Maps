# SCCT Versus - Warehouse assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to Warehouse (`WareD`, `WareP`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `FX_WAR_warp.usx` | `Packages/StaticMeshes` | 3 static meshes |
| `stm_war.usx` | `Packages/StaticMeshes` | 153 static meshes |
| `SFX_WAR_xbox.utx` | `Packages/Textures` | 11 textures, 7 materials |
| `txt_war.utx` | `Packages/Textures` | 137 textures, 72 materials |
| `WareD-i.utc` | `Packages/Textures` | Map-selection image for `WareD` |
| `WareP-i.utc` | `Packages/Textures` | Map-selection image for `WareP` |
| `MC_war_ext.mux` | `Packages/Sounds` | Ambient sound stream |
| `WareD.uas` | `Packages/Sounds` | Sound list for `WareD` |
| `WareP.uas` | `Packages/Sounds` | Sound list for `WareP` |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md), [Shared props](../../svm-shared-props/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-warehouse-v1.0.0).
