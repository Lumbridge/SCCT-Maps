# SCCT Versus - River Mall assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to River Mall (`RiveD`, `RiveE`, `RiveP`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `ERM_STM.usx` | `Packages/StaticMeshes` | 3 static meshes |
| `Mall_tibu_stc.usx` | `Packages/StaticMeshes` | 59 static meshes |
| `STM_MALL.usx` | `Packages/StaticMeshes` | 198 static meshes |
| `Mall_tibu.utx` | `Packages/Textures` | 48 textures, 21 materials |
| `RiveD-i.utc` | `Packages/Textures` | Map-selection image for `RiveD` |
| `RiveE-i.utc` | `Packages/Textures` | Map-selection image for `RiveE` |
| `RiveP-i.utc` | `Packages/Textures` | Map-selection image for `RiveP` |
| `TXT_MAL.utx` | `Packages/Textures` | 107 textures, 93 materials |
| `MAL_anm.ukx` | `Packages/Animations` | 1 skeletal mesh, 1 animation set |
| `RiveD.uas` | `Packages/Sounds` | Sound list for `RiveD` |
| `RiveE.uas` | `Packages/Sounds` | Sound list for `RiveE` |
| `RiveP.uas` | `Packages/Sounds` | Sound list for `RiveP` |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md), [Shared props](../../svm-shared-props/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-river-mall-v1.0.0).
