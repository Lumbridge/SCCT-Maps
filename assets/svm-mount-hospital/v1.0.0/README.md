# SCCT Versus - Mount Hospital assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to Mount Hospital (`MounE`, `MounS`, `MounU`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `EMH_STM.usx` | `Packages/StaticMeshes` | 2 static meshes |
| `SM_UMP.usx` | `Packages/StaticMeshes` | 8 static meshes |
| `UMPMHOSM.usx` | `Packages/StaticMeshes` | 3 static meshes |
| `MHOsfx_xbox.utx` | `Packages/Textures` | 4 textures, 2 materials |
| `MHOtex_xbox.utx` | `Packages/Textures` | 21 textures, 11 materials |
| `MounE-i.utc` | `Packages/Textures` | Map-selection image for `MounE` |
| `MounS-i.utc` | `Packages/Textures` | Map-selection image for `MounS` |
| `MounU-i.utc` | `Packages/Textures` | Map-selection image for `MounU` |
| `TX_UMP.utx` | `Packages/Textures` | 22 textures, 29 materials |
| `UMPANIM.utx` | `Packages/Textures` | 31 textures, 1 material |
| `Amb_Mount.uax` | `Packages/Sounds` | 21 sounds |
| `MounE.uas` | `Packages/Sounds` | Sound list for `MounE` |
| `MounS.uas` | `Packages/Sounds` | Sound list for `MounS` |
| `MounU.uas` | `Packages/Sounds` | Sound list for `MounU` |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md), [Aquarius](../../svm-aquarius/v1.0.0/README.md), [Krauser Lab](../../svm-krauser-lab/v1.0.0/README.md), [Orphanage](../../svm-orphanage/v1.0.0/README.md), [Prison](../../svm-prison/v1.0.0/README.md), [Skyscraper](../../svm-skyscraper/v1.0.0/README.md), [Station](../../svm-station/v1.0.0/README.md), [Warehouse](../../svm-warehouse/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-mount-hospital-v1.0.0).
