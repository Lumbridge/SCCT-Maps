# GoldenEye 007: Reloaded — Outpost assets v1.0.0

Static meshes from the Outpost multiplayer scenery, with their textures and materials, for your own SCCT maps. Install from the SCCT Map Manager's **Asset Packs** section. It installs `Packages/StaticMeshes/GE007_Outpost.usx` only.

The [editable Outpost port](../../../ports/goldeneye-007-reloaded/outpost/README.md) uses the same package. Props are separate meshes with base-centred pivots. Large scenery may be split into `_C` chunks. Check collision and the approximated shaders before use. No playable map is included.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/ge007-outpost-v1.0.0). Close the editor before installing and keep any packages you have edited.
