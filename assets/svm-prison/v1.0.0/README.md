# SCCT Versus - Prison assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to Prison (`PrisD`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `Penitentiary_STM.usx` | `Packages/StaticMeshes` | 294 static meshes |
| `Prison_STC.usx` | `Packages/StaticMeshes` | 167 static meshes |
| `Penitentiary_TXT.utx` | `Packages/Textures` | 467 textures, 44 materials |
| `PrisD-i.utc` | `Packages/Textures` | Map-selection image for `PrisD` |
| `Prison_TEX.utx` | `Packages/Textures` | 76 textures, 23 materials |
| `Amb_Penitentiary.uax` | `Packages/Sounds` | 40 sounds |
| `PrisD.uas` | `Packages/Sounds` | Sound list for `PrisD` |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md), [Aquarius](../../svm-aquarius/v1.0.0/README.md), [Deftech Belew](../../svm-deftech-belew/v1.0.0/README.md), [Mount Hospital](../../svm-mount-hospital/v1.0.0/README.md), [Station](../../svm-station/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-prison-v1.0.0).
