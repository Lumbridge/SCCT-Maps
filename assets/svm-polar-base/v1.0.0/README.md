# SCCT Versus - Polar Base assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to Polar Base (`PolaD`, `PolaE`, `PolaP`, `PolaT`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `Map17_STM.usx` | `Packages/StaticMeshes` | 137 static meshes |
| `Map17_TXT.utx` | `Packages/Textures` | 102 textures, 35 materials |
| `PolaD-i.utc` | `Packages/Textures` | Map-selection image for `PolaD` |
| `PolaE-i.utc` | `Packages/Textures` | Map-selection image for `PolaE` |
| `PolaP-i.utc` | `Packages/Textures` | Map-selection image for `PolaP` |
| `PolaT-i.utc` | `Packages/Textures` | Map-selection image for `PolaT` |
| `map17_anm.ukx` | `Packages/Animations` | 4 skeletal meshes, 4 animation sets |
| `Amb_Polarbase.uax` | `Packages/Sounds` | 30 sounds |
| `MC_pol_vent.mux` | `Packages/Sounds` | Ambient sound stream |
| `PolaD.uas` | `Packages/Sounds` | Sound list for `PolaD` |
| `PolaE.uas` | `Packages/Sounds` | Sound list for `PolaE` |
| `PolaP.uas` | `Packages/Sounds` | Sound list for `PolaP` |
| `PolaT.uas` | `Packages/Sounds` | Sound list for `PolaT` |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md), [TME30-33](../../svm-tme/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-polar-base-v1.0.0).
