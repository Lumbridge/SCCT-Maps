# SCCT Versus - Steel Squat assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to Steel Squat (`SteeD`, `SteeE`, `SteeP`, `SteeT`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `ESS_STM.usx` | `Packages/StaticMeshes` | 1 static mesh |
| `SQU13_STM.usx` | `Packages/StaticMeshes` | 182 static meshes |
| `SQU13_txt.utx` | `Packages/Textures` | 173 textures, 57 materials |
| `SteeD-i.utc` | `Packages/Textures` | Map-selection image for `SteeD` |
| `SteeE-i.utc` | `Packages/Textures` | Map-selection image for `SteeE` |
| `SteeP-i.utc` | `Packages/Textures` | Map-selection image for `SteeP` |
| `SteeT-i.utc` | `Packages/Textures` | Map-selection image for `SteeT` |
| `sqt13_anm.ukx` | `Packages/Animations` | 2 skeletal meshes, 2 animation sets |
| `Amb_Squat.uax` | `Packages/Sounds` | 57 sounds |
| `MC_mur_destroy.mux` | `Packages/Sounds` | Ambient sound stream |
| `MC_Squ_rue_ext.mux` | `Packages/Sounds` | Ambient sound stream |
| `SteeD.uas` | `Packages/Sounds` | Sound list for `SteeD` |
| `SteeE.uas` | `Packages/Sounds` | Sound list for `SteeE` |
| `SteeP.uas` | `Packages/Sounds` | Sound list for `SteeP` |
| `SteeT.uas` | `Packages/Sounds` | Sound list for `SteeT` |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md), [Aquarius](../../svm-aquarius/v1.0.0/README.md), [River Mall](../../svm-river-mall/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-steel-squat-v1.0.0).
