# SCCT Versus - Schermerhorn assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to Schermerhorn (`ScheE`, `ScheU`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `fixsm.usx` | `Packages/StaticMeshes` | 1 static mesh |
| `SM_Egouts.usx` | `Packages/StaticMeshes` | 276 static meshes |
| `fixtxt.utx` | `Packages/Textures` | 1 texture |
| `ScheE-i.utc` | `Packages/Textures` | Map-selection image for `ScheE` |
| `ScheU-i.utc` | `Packages/Textures` | Map-selection image for `ScheU` |
| `SFX_SCH_xbox.utx` | `Packages/Textures` | 25 textures, 7 materials |
| `Tex_Egouts.utx` | `Packages/Textures` | 114 textures, 26 materials |
| `Tex_Egouts_XBox.utx` | `Packages/Textures` | 44 textures, 2 materials |
| `Amb_Egouts.uax` | `Packages/Sounds` | 31 sounds |
| `ScheE.uas` | `Packages/Sounds` | Sound list for `ScheE` |
| `ScheU.uas` | `Packages/Sounds` | Sound list for `ScheU` |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-schermerhorn-v1.0.0).
