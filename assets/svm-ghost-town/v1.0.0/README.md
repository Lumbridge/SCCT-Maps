# SCCT Versus - Ghost Town assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to Ghost Town (`GhosS`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `GhosS-i.utc` | `Packages/Textures` | Map-selection image for `GhosS` |
| `GhosS.uas` | `Packages/Sounds` | Sound list for `GhosS` |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md), [Steel Squat](../../svm-steel-squat/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-ghost-town-v1.0.0).
