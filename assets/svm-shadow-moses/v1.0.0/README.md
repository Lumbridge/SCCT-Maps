# SCCT Versus - Shadow Moses assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to Shadow Moses (`ShadD`, `ShadP`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `Shadow_V2.usx` | `Packages/StaticMeshes` | 3 static meshes, 2 textures |
| `ShadowMoses_SM.usx` | `Packages/StaticMeshes` | 66 static meshes |
| `ShadD-i.utc` | `Packages/Textures` | Map-selection image for `ShadD` |
| `Shadow_V2.utx` | `Packages/Textures` | 2 textures |
| `ShadowMoses_T.utx` | `Packages/Textures` | 120 textures, 7 materials |
| `ShadP-i.utc` | `Packages/Textures` | Map-selection image for `ShadP` |
| `ShadD.uas` | `Packages/Sounds` | Sound list for `ShadD` |
| `ShadP.uas` | `Packages/Sounds` | Sound list for `ShadP` |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md), [Shared props](../../svm-shared-props/v1.0.0/README.md), [Aquarius](../../svm-aquarius/v1.0.0/README.md), [Deftech Belew](../../svm-deftech-belew/v1.0.0/README.md), [Factory](../../svm-factory/v1.0.0/README.md), [TME30-33](../../svm-tme/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-shadow-moses-v1.0.0).
