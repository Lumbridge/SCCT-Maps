# SCCT Versus - Factory assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to Factory (`FactD`, `FactE`, `FactP`, `FactT`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `FAC_STM.usx` | `Packages/StaticMeshes` | 145 static meshes |
| `POC_Fac_SM.usx` | `Packages/StaticMeshes` | 13 static meshes |
| `FAC_TXT.utx` | `Packages/Textures` | 72 textures, 20 materials |
| `FactD-i.utc` | `Packages/Textures` | Map-selection image for `FactD` |
| `FactE-i.utc` | `Packages/Textures` | Map-selection image for `FactE` |
| `FactP-i.utc` | `Packages/Textures` | Map-selection image for `FactP` |
| `FactT-i.utc` | `Packages/Textures` | Map-selection image for `FactT` |
| `FAC_anm.ukx` | `Packages/Animations` | 7 skeletal meshes, 7 animation sets |
| `Amb_factory.uax` | `Packages/Sounds` | 40 sounds |
| `FactD.uas` | `Packages/Sounds` | Sound list for `FactD` |
| `FactE.uas` | `Packages/Sounds` | Sound list for `FactE` |
| `FactP.uas` | `Packages/Sounds` | Sound list for `FactP` |
| `FactT.uas` | `Packages/Sounds` | Sound list for `FactT` |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-factory-v1.0.0).
