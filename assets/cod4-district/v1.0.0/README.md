# Call of Duty 4 - District assets v1.0.0

Static meshes and textures from the Call of Duty 4 multiplayer map District (`mp_citystreets`), for your own SCCT maps. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `COD4_citystreets.usx` | `Packages/StaticMeshes` | 751 static meshes (source props and leftover world geometry) with embedded materials |
| `COD4_citystreets_TXT.utx` | `Packages/Textures` | 328 textures, 325 materials |

The texture package has exact copies of the materials in the mesh package. Use it to texture your own BSP or meshes. Maps that use it must ship that `.utx`. The [editable BSP port](../../../ports/call-of-duty-4/district/README.md) uses the same mesh package.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/cod4-district-v1.0.0).
