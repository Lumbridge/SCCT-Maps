# Call of Duty 4 - Bog assets v1.0.0

Static meshes and textures from the Call of Duty 4 multiplayer map Bog (`mp_bog`), for your own SCCT maps. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `COD4_bog.usx` | `Packages/StaticMeshes` | 454 static meshes (source props and leftover world geometry) with embedded materials |
| `COD4_bog_TXT.utx` | `Packages/Textures` | 334 textures, 326 materials |

The texture package has exact copies of the materials in the mesh package. Use it to texture your own BSP or meshes. Maps that use it must ship that `.utx`. The [editable BSP port](../../../ports/call-of-duty-4/bog/README.md) uses the same mesh package.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/cod4-bog-v1.0.0).
