# SCCT Versus - Skyscraper assets v1.0.0

The asset packages from the SCCT Versus 4.0 install that belong to Skyscraper (`SkysD`, `SkysP`): its meshes, textures, animations and sounds, plus each map's sound list and menu image. Install from the SCCT Map Manager's **Asset Packs** section.

| Package | Folder | Contents |
| --- | --- | --- |
| `SKV22_STM.usx` | `Packages/StaticMeshes` | 36 static meshes |
| `SM_SKY09.usx` | `Packages/StaticMeshes` | 111 static meshes |
| `stm_spy.usx` | `Packages/StaticMeshes` | 91 static meshes |
| `SKV22_TXT.utx` | `Packages/Textures` | 41 textures, 9 materials |
| `SkysD-i.utc` | `Packages/Textures` | Map-selection image for `SkysD` |
| `SkysP-i.utc` | `Packages/Textures` | Map-selection image for `SkysP` |
| `TX_SKY09.utx` | `Packages/Textures` | 113 textures, 48 materials |
| `txt_spy.utx` | `Packages/Textures` | 104 textures, 32 materials |
| `Amb_Skyscraper.uax` | `Packages/Sounds` | 6 sounds |
| `SkysD.uas` | `Packages/Sounds` | Sound list for `SkysD` |
| `SkysP.uas` | `Packages/Sounds` | Sound list for `SkysP` |

These packages also load from [Core game assets](../../svm-core/v1.0.0/README.md), [Aquarius](../../svm-aquarius/v1.0.0/README.md), [Bank](../../svm-bank/v1.0.0/README.md), [Club House](../../svm-club-house/v1.0.0/README.md), [Mount Hospital](../../svm-mount-hospital/v1.0.0/README.md), [River Mall](../../svm-river-mall/v1.0.0/README.md), [Station](../../svm-station/v1.0.0/README.md). Install those packs too.

These are unmodified copies of Ubisoft's files. Your game may already have them. The pack is for map makers who want the set in one place.

[Release and downloads](https://github.com/Lumbridge/SCCT-Maps/releases/tag/svm-skyscraper-v1.0.0).
